## 해석
- lb01(192.168.64.7)의 `/health` 응답 본문이 `ok lab02` 인 것은 HAProxy 가 요청을 백엔드 웹 서버로 넘기고 그 응답을 돌려주기 때문이다. 점검 때마다 `ok lab01` 과 `ok lab02` 가 번갈아 나올 수 있다(roundrobin). 이 줄이 성공이면 "LB를 거쳐 웹 서버까지 도달한다"는 확인이다.
- app01 과 db01 에 HTTP 점검이 없는 것은 설계다. 점검 대상 그룹(`HTTP_GROUPS`)은 webservers 와 loadbalancers 이고, app01 은 방화벽이 웹 서버에서 온 요청만 허용해 맥에서 직접 칠 수 없으며 db01 은 MySQL 이라 HTTP 응답이 없다. 두 서버는 서비스 active 여부로 확인한다.
- 개선: 점검 줄에 서버 이름 열을 붙여 어느 서버를 본 줄인지 분명히 했다(`HTTP OK lb01 http://... ok lab02`).
