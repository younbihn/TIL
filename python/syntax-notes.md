# 파이썬 문법 노트

## dict에서 값 꺼내기
- `d["키"]` → 없으면 KeyError로 프로그램이 죽음
- `d.get("키")` → 없으면 None 반환, 계속 진행
- 없을 수도 있는 조회(로그인 등)에는 .get()

## None과 truthy/falsy
- None = "값이 없음"을 뜻하는 특별한 값 (0이나 빈 문자열과 다름)
- 파이썬은 None, 0, "", [], {} 를 거짓으로 취급
- 그래서 `not user` = "user가 None이면 참"

## 단축 평가 (short-circuit)
- `A or B` → A가 참이면 B는 실행조차 안 됨
- `A and B` → A가 거짓이면 B는 실행조차 안 됨
- 활용: `if not user or not verify(user["key"])`
  → user가 None이면 오른쪽을 건너뛰어 에러 방지
- **조건의 순서가 문법적 의미를 가진다**

## 상수 표기
- 파이썬에 상수 문법은 없음. 대문자 이름이 "건드리지 말라"는 관례
- 일반 변수는 snake_case (소문자 + 밑줄)
- 설정값은 한 곳에 모으기 → 흩어진 숫자(매직 넘버)는 피할 것
