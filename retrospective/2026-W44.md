### 배운 것 중 핵심
- lineinfile 의 `^#?` 패턴은 주석 처리된 기본값까지 잡기 위한 것
- handlers 는 changed 일 때만, 플레이 끝에, 중복 제거되어 1회만 실행
- validate 로 배포 전 검사. 설정 데몬은 대개 검사 모드(-t, -c)를 제공한다
- firewalld 의 permanent/runtime 분리는 자기 접속을 끊었을 때의 복구 장치
- changed_when: false 는 조회성 명령에만. 상태를 바꾸는 명령에 붙이면
  멱등성을 위장하게 된다 (어제 발견한 makestep 문제의 원인)
- facts 는 ansible_facts 딕셔너리에서 꺼내는 것이 표준. 최상위 자동 주입은 제거 예정

### 측정 방식의 한계 (기록해둘 것)
시각 오차 측정값 = 실제 시계 오차 + 플레이 경과 시간.
ansible_facts.date_time 은 플레이 시작 시점(Gathering Facts)의 값이고
lookup('pipe', 'date +%s') 는 해당 태스크 실행 시점의 값이기 때문이다.
정상 서버에서도 2~3초가 측정되므로 임계치를 5초로 두었다.
목적이 "수십 일 규모의 오차 감지"이므로 이 정밀도로 충분하다.
